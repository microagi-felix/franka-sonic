## Round 3 in one paragraph (read this first)

(a) **Both lanes put their entire result in the last quarter of the run and

MIMIC_SPAWN_YAW=0.4 MIMIC_ARM_NOISE_STD=0.02`). Felix's decision
(2026-09-05 08:05 UTC): **warm-restart each lane from its own round-2
`checkpoint-20000` for 20 000 more steps, fresh optimizer and cosine schedule,
on the union of the 891 wide and the 1024 eval-matched episodes.** Everything
else is identical between the lanes and identical to round 2: hyper-parameters,
step budget, checkpoint interval, screening rule, evaluation binding, seeds,
rate, replan interval, horizon. The recipe is therefore "40k steps with a

### WP 11.0 — the union demo folder

The two exports use identical shard basenames (`demos_shard0..7.hdf5`), and
`label_tokens.py` keys clips by **(shard basename, demo name)** while
`demos_to_sonic_pkl.py` names clips by the **shard index** parsed from the
basename — so a plain union would collide. Each source set therefore keeps its
own subdirectory, the eval-matched shards get basenames with indices **16–23**
(the wide export already uses 0–15; two-digit names sort numerically inside
their own directory), and each HDF5's relative video path
(`demos_shard<i>_videos/…`, relative to the HDF5's own directory) is satisfied
by a symlink beside it:

```
U=~/runs/franka-sonic/shared/2026-09-05_demos-union
R2=~/runs/franka-sonic/shared/2026-09-04_demos/out/export
R3=~/runs/franka-sonic/shared/2026-09-04_demos-2/out/export
mkdir -p $U/out/export/a_evalmatched $U/out/export/b_wide $U/logs
for i in 0 1 2 3 4 5 6 7; do
  ln    $R3/demos_shard$i.hdf5     $U/out/export/a_evalmatched/$(printf 'demos_shard%d.hdf5' $((16+i)))     # hard link: distinct basename, resolves to itself
  ln -s $R3/demos_shard${i}_videos $U/out/export/a_evalmatched/demos_shard${i}_videos                      # the HDF5's relative video path uses its ORIGINAL stem
done
for i in $(seq 0 15); do
  ln -s $R2/demos_shard$i.hdf5     $U/out/export/b_wide/demos_shard$i.hdf5
  ln -s $R2/demos_shard${i}_videos $U/out/export/b_wide/demos_shard${i}_videos
done
```

If `ln` (hard link) is refused on this filesystem, `cp` the eight R3 shards
instead (1.5 GB) — never `mv`. Write `$U/README.md` (what, why, the two
sources, the naming rule) and a `$U/config.json` naming both source runs.
