## Round 2 in one paragraph (read this first)

Round 1 (P0–P6) proved the pipeline and produced a decoder that works: lane A
0/20, lane B 1/20, A-oracle 20/20, B-oracle 19/20 on 76 scripted-demo episodes
and a 2000-step fine-tune. Both policies were starved — 76 episodes, ~1.25

and a much longer fine-tune with an explicit stopping rule**, then compares

the lanes except the action interface: same episodes, same fine-tune
hyper-parameters and step budget, same stopping rule, same evaluation binding,
seeds, rate, replan interval and horizon.

## 2. Work packages

### WP 8.0 — new reference set

`harness/lane_b/demos_to_sonic_pkl.py` (+ the left/right mirrors, verified

### WP 8.2 — ceiling tests decide
Ceiling-test checkpoints every 500 iterations from iteration 1000: label the
**first 20 export episodes only** (add `--max-episodes N` to
`harness/lane_b/label_tokens.py` and the stage if it has no such flag — full
labelling of 1000 episodes is a P8.3 job, not a per-checkpoint one), then
`bakeoff run lane_b oracle_b --onnx <export> --tokens <labels> --rollouts 20`.
Keep the series in STATUS: checkpoint → replay rad → grasp-frame flange L/R cm
→ B-oracle N/20 → mean progress.

Stop when a checkpoint reaches **≥ 18/20**, or when two consecutive checkpoints
fail to beat the best, or at the 4 h cap. The best checkpoint is the winner;
copy its finals to `~/runs/franka-sonic/lane_b/final/p8/<name>/`.
If nothing clears 15/20, that is a real finding: write it, run the P5
diagnostics that apply (plant swap replay, trace FK against the demo), and only
then consider a second 4 h run with more iterations.

### WP 8.3 — relabel the whole set

`out/gr00t_v2_sonic`. It must contain the **same episode count** as lane A's
`out/gr00t_v2` — the gate checks equality, because a lane trained on a
different episode set is not a comparison. Expect ~50 min at 1000 episodes.

### WP 8.4 — record
One STATUS line with: reference-set size, winner checkpoint, its replay error,
its ceiling result, the full series, the relabelled episode/frame count, and
the finals path.
