
Check the flags against `--help` first (the script's names may differ); keep
the hyperparameters identical to this list — lane B will use exactly the same

`<run>/logs/`, record the PID, poll in bounded foreground loops.

### WP 1.6 — eval, 20 rollouts (run folder `…_eval`)

```
PYTHONUSERBASE=~/env/pyuser-fr3 /isaac-sim/python.sh -m evaluation.eval \
    --run-folder <run>/out/eval --client <the joint client> \
    --host 127.0.0.1 --port <port> --embodiment franka_dual \
    --rate 50 --replan-every 20 --rollouts 20 --max-steps <enough for 50 Hz> \
    --no-splat --headless
```

`--max-steps` must scale with the rate: whatever the 15 Hz default episode
length was, multiply by 50/15. `evaluation.eval` refuses to resume a folder
with a different task/rate — use a fresh folder if you change either. The gate
wants **≥ 20 episodes** in `out/eval/eval_results.csv`.

  STATUS.md and push.
